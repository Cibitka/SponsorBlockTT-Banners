# Шаблоны баннеров

Загружайте PNG или JPG в эту папку. В SponsorBlock Companion откройте «Шаблоны с GitHub», укажите `Cibitka/SponsorBlockTT-Banners` и нажмите «Обновить». При следующем запуске детектора каталог проверяется автоматически.

Используйте только вырезку баннера. Имена файлов могут содержать латинские буквы, цифры, дефисы и подчёркивания. Размер файла до 1 МБ.
